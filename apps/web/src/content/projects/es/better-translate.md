Better Translate trata las traducciones como TypeScript de primera clase. Escribes la configuración una vez y obtienes la misma API y los mismos tipos en todas partes: Next.js, Astro, React, TanStack Router, Node, Bun y Expo.

Las claves se infieren y las interpolaciones tienen tipos, así que una clave que falta o está mal escrita es un error de tipos y no un texto vacío en producción.

Un CLI integrado genera los archivos de traducción con cualquier proveedor de IA, o con modelos locales a través de Ollama, para que nadie tenga que escribir un archivo de idioma a mano.
