Las skills son la forma en que les enseño a los agentes de código a trabajar como yo. Cada una es un `SKILL.md` con reglas para un tipo de tarea: escribir código, revisar pull requests, diseñar el frontend, planificar el backend, estructurar apps, gestionar issues y mantener al día los archivos de agentes de un proyecto.

Los mismos archivos funcionan en Claude Code, Codex, ChatGPT, Cursor, Grok Build y cualquier agente compatible con el formato Agent Skills. El repositorio se publica como plugin para cada uno de ellos, y a través de skills.sh para todo lo demás.

Cada skill de este sitio se lee directamente del repositorio cuando se construye el sitio, así que las [páginas de skills](/skills) siempre coinciden con lo que usan los agentes.
